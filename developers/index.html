Read-only starting point

These commands inspect published resources; they do not require credentials or initiate a payment.

python -m venv .venv
python -m pip index versions szl
curl -i --max-time 15 https://a-11-oy.com/api/a11oy/v1/honest

A responding HTTP endpoint does not establish source parity, model training or deployment readiness.

Integration admission

  1. Source: inspect a pinned GitHub commit and required checks, reviews and provenance.
  2. Artifact: bind source, model base, trainer state, data rights, evaluation protocol and hashes.
  3. Runtime: compare the actual hosted revision with admitted GitHub source, then verify authentication and failure paths.
  4. Payments: x402 v2 separates PAYMENT-REQUIRED, PAYMENT-SIGNATURE and PAYMENT-RESPONSE. A 402 challenge alone is not a settled transaction. Review the protocol specification.
  5. Release: verify actual published PyPI distributions and cryptographic provenance.

Never paste private keys, tokens, signed payment payloads or training data into public issues, dashboards or prompts. This page supplies no private credentials.
